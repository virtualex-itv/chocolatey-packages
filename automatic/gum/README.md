# <img src="https://cdn.jsdelivr.net/gh/virtualex-itv/chocolatey-packages@a3f798bd912eac816b4ac8d49f43dccdec6f3873/icons/gum.png" width="48" height="48"/> [gum](https://community.chocolatey.org/packages/gum)

Gum provides highly configurable, ready-to-use utilities to help you write useful shell scripts and dotfiles aliases with just a few lines of code. Ask for input, choose from lists, filter, confirm, spin, style, format, page and more, without writing any Go.

### Features

* Interactive building blocks for shell scripts: input, write, choose, filter, confirm, file, table, pager, spin, join, style and format
* Works in any shell, including PowerShell, cmd and Git Bash
* Highly configurable through flags and environment variables

### Package Notes

* This package installs the portable gum.exe, which Chocolatey shims onto your PATH.
* The 64-bit build is installed on 64-bit Windows and the 32-bit build on 32-bit Windows.

**Please Note**: This is an automatically updated package. If you find it is out of date by more than a day or two, please contact the maintainer(s) and let them know the package is no longer updating correctly.
