# <img src="https://cdn.jsdelivr.net/gh/virtualex-itv/chocolatey-packages@a26b69aa1e735e944b000599ee83e328d3939712/icons/capptivo.png" width="48" height="48"/> [capptivo](https://community.chocolatey.org/packages/capptivo)

Capptivo is a free, open-source alternative to Screen Studio and Cursorful. It records your screen and turns the recording into a polished demo video, with effects applied automatically.

### Features

* Smart follow-cursor zoom and click-based automatic zooms
* Editor presets for styling a recording quickly
* On-device captions (needs a system whisper.cpp `whisper-cli` binary; the model weights are downloaded on first use)
* No account required to record or edit

### Package Notes

* This package installs the 64-bit MSI installer.
* The Windows installers are not code signed.
* Capptivo runs on the Microsoft Edge WebView2 Runtime, which is installed as a dependency.

**Please Note**: This is an automatically updated package. If you find it is out of date by more than a day or two, please contact the maintainer(s) and let them know the package is no longer updating correctly.
