# <img src="https://cdn.jsdelivr.net/gh/virtualex-itv/chocolatey-packages@eed0f02fcb1ad8752fff33701564fd1754200461/icons/deskreen.png" width="48" height="48"/> [deskreen](https://community.chocolatey.org/packages/deskreen)

Deskreen CE (Community Edition) turns any device with a web browser into a secondary screen for your computer. It is an Electron application that uses WebRTC to stream your computer screen live to a web browser on any device, with no software needed on the receiving device.

### Package Notes

* This is the open-source Community Edition, which has limited features. The Deskreen website describes a Pro version with more features.
* This package installs the 64-bit MSI on 64-bit Windows and the 32-bit MSI on 32-bit Windows.

**Please Note**: This is an automatically updated package. If you find it is out of date by more than a day or two, please contact the maintainer(s) and let them know the package is no longer updating correctly.
