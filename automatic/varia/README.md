# <img src="https://cdn.jsdelivr.net/gh/virtualex-itv/chocolatey-packages@651e9702250a0ddccfc8ae41eaef7d69ee819a32/icons/varia.png" width="48" height="48"/> [varia](https://community.chocolatey.org/packages/varia)

Varia is a free, open source download manager for Windows and Linux. It handles regular file downloads, torrents, and video and audio streams, and is a graphical frontend for aria2 and yt-dlp.

### Features

* Regular file downloads with pause and resume, powered by aria2
* Torrent and magnet link downloads
* Video and audio downloads from the sites yt-dlp supports
* Optional browser extension for sending downloads to Varia

### Package Notes

* This package installs the 64-bit installer for all users. On ARM64 Windows it runs under emulation.
* The installer is not code signed, so Windows SmartScreen may warn on a manual download.

**Please Note**: This is an automatically updated package. If you find it is out of date by more than a day or two, please contact the maintainer(s) and let them know the package is no longer updating correctly.
