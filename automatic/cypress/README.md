# <img src="https://cdn.jsdelivr.net/gh/virtualex-itv/chocolatey-packages@756d1bc47d24eb9b748437427f934eda86656b60/icons/cypress.png" width="48" height="48"/> [cypress](https://community.chocolatey.org/packages/cypress)

Cypress is a front-end testing tool built for the modern web. It runs end-to-end and component tests for anything that runs in a browser, with a desktop app that shows each command and the page as the test runs.

### Package Notes

* This package installs the Cypress desktop app, the same binary that `npm install cypress` downloads, to `C:\tools\Cypress` (or your Chocolatey tools location) and adds a Cypress shortcut to your desktop.
* Cypress needs 64-bit Windows 10 or 11.
* The Cypress app is free and open source (MIT). Cypress Cloud, the paid hosted service, is separate and is not installed by this package.

**Please Note**: This is an automatically updated package. If you find it is out of date by more than a day or two, please contact the maintainer(s) and let them know the package is no longer updating correctly.
