MangoDisk is a safety-first disk cleanup and storage analysis tool. It finds reclaimable space, shows where your disk space is going, and manages privacy traces, startup items and installed applications.

### Features

* Deep cleanup of system, application and browser caches, developer tool caches, container caches and project build artifacts
* Large file cleanup and duplicate file cleanup that always keeps one copy in every group
* Disk space analysis with treemap and sunburst views
* Privacy cleanup, application uninstall with leftover removal, and startup item management
* System optimization and maintenance fixes, with a history of every operation
* CPU, memory, network and disk monitoring from the system tray

### Package Notes

* This package installs the 64-bit installer for the user running Chocolatey (a per-user install).
* AI explanations of cleanup items include a free daily allowance in official releases; you can connect your own AI service instead.
* MangoDisk runs on the Microsoft Edge WebView2 Runtime (111.0.1661.62 or later), which is installed as a dependency.

**Please Note**: This is an automatically updated package. If you find it is out of date by more than a day or two, please contact the maintainer(s) and let them know the package is no longer updating correctly.
