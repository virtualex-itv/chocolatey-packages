# <img src="https://cdn.jsdelivr.net/gh/virtualex-itv/chocolatey-packages@2bd9fbc8afbdc3e9f8c61b05c4ebdebdd690df95/icons/hydrogen.png" width="48" height="48"/> [hydrogen](https://community.chocolatey.org/packages/hydrogen)

Hydrogen is an advanced, open source drum machine. It provides a pattern-based sequencer, a song editor, a mixer with effects, and support for multi-layer drum kits, with MIDI input and audio export.

### Features

* Pattern-based sequencer with an unlimited number of patterns
* Song editor for chaining patterns into a full arrangement
* Multi-layer drum kit support with velocity layers
* Mixer with per-instrument effects
* MIDI input and output, and export to audio files

### Package Notes

* This package installs the 64-bit installer.
