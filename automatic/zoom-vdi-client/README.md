The Zoom VDI client (Zoom Workplace VDI) is the Zoom app for virtual desktops. It is installed inside the virtual desktop or on the session host. Together with the Zoom VDI plugin on the device the user connects from, it moves audio and video processing out of the virtual desktop to that device, which gives better call quality and lowers the load on the host.

### Package Notes

* Install this package in the virtual desktop or on the session host. Install [zoom-vdi-universal-plugin](https://community.chocolatey.org/packages/zoom-vdi-universal-plugin) on the devices users connect from.
* The VDI client and plugin are released together with the same version. Zoom documents which plugin versions each client version supports.
* Zoom publishes a 64-bit installer only.

**Please Note**: This is an automatically updated package. If you find it is out of date by more than a day or two, please contact the maintainer(s) and let them know the package is no longer updating correctly.
