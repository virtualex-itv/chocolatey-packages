# <img src="https://cdn.jsdelivr.net/gh/virtualex-itv/chocolatey-packages@0249bff8b639693e165fafe76b38d1988e52fe7d/icons/gemini-desktop.png" width="48" height="48"/> [gemini-desktop](https://community.chocolatey.org/packages/gemini-desktop)

Gemini for desktop is Google's AI assistant as a native Windows app. Press Alt + Space from anywhere to summon Gemini over whatever you are working on, and use it alongside Gmail, Drive, Docs and Calendar.

The app is free to use with a Google Account. Selected features require a paid Google AI subscription (users 18+), and features vary by account type and region. Requires Windows 10 or later (x64).

**Please Note**: This is an automatically updated package. If you find it is out of date by more than a day or two, please contact the maintainer(s) and let them know the package is no longer updating correctly.
