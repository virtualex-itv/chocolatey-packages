# <img src="https://cdn.jsdelivr.net/gh/virtualex-itv/chocolatey-packages@f12f387e671554108fd662528a5314ec2ad8971e/icons/altus.png" width="48" height="48"/> [altus](https://community.chocolatey.org/packages/altus)

Altus is an Electron-based desktop client for WhatsApp Web. It adds themes and support for several WhatsApp accounts side by side.

### Package Notes

* Altus is an unofficial client. It is not made by, affiliated with or endorsed by WhatsApp or Meta, and it needs a WhatsApp account that is linked from the phone as usual.
* This package installs the 64-bit installer published by the Altus project on GitHub. The installer is not code signed, so Windows SmartScreen may warn if it is downloaded by hand. Chocolatey verifies the SHA-256 checksum of the download instead.

**Please Note**: This is an automatically updated package. If you find it is out of date by more than a day or two, please contact the maintainer(s) and let them know the package is no longer updating correctly.
