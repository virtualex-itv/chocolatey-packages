## Usage

To install Orkas, run the following command from the command line or from PowerShell:

```powershell
choco install orkas
```

To upgrade Orkas, run the following command from the command line or from PowerShell:

```powershell
choco upgrade orkas
```

To uninstall Orkas, run the following command from the command line or from PowerShell:

```powershell
choco uninstall orkas
```

## Description

Orkas is a local-first multi-agent desktop app: an AI assistant that works as a team. You tell the Commander what you need; it finishes tasks itself, or plans the steps and brings in specialist agents (16 ship with the app) for research, content and slide decks, images, video and voice, websites and code, Office files and e-commerce work.

### Features

* Projects that keep goals, rules, memory and files across conversations
* To-dos with auto-advance, and scheduled automations (hourly to monthly)
* Connectors such as Gmail, Google Calendar, Drive, Notion, Slack and Shopify; Orkas asks before it sends, posts or deletes anything
* The built-in Orkas model, or your own provider keys (Claude, OpenAI, Gemini, DeepSeek and others, or a local OpenAI-compatible endpoint)

### Package Notes

* This package installs the 64-bit packaged desktop app, which asks you to sign in on first launch.
* It is free to start and includes 500 credits for the built-in Orkas model. After that you buy credits, choose a paid plan or add your own provider keys (provider charges are separate). Some features, such as cloud sync, shared projects and publishing web apps, need the packaged app and may need a paid plan.

**Please Note**: This is an automatically updated package. If you find it is out of date by more than a day or two, please contact the maintainer(s) and let them know the package is no longer updating correctly.
