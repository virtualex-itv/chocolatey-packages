## Usage

To install Stirling PDF, run the following command from the command line or from PowerShell:

```powershell
choco install stirling-pdf
```

To upgrade Stirling PDF, run the following command from the command line or from PowerShell:

```powershell
choco upgrade stirling-pdf
```

To uninstall Stirling PDF, run the following command from the command line or from PowerShell:

```powershell
choco uninstall stirling-pdf
```

## Description

Stirling PDF is an open-core PDF editing platform. This package installs its Windows desktop app, which edits, merges, splits, converts, compresses, OCRs, signs and redacts PDFs, with the tools running on your own computer.

### Package Notes

* This package installs the 64-bit MSI installer for all users. On ARM64 Windows it runs under x64 emulation.
* The desktop app is free for individuals. Its desktop components are covered by the Stirling PDF User License, which requires a paid subscription for production or business use (see the license linked on this page and https://www.stirlingpdf.com/terms).
* On first launch the app offers to sign in to Stirling Cloud, to connect to a self-hosted server, or to continue without signing in (Local Only mode). Tools that need a server are not available in Local Only mode.
* The app runs on the Microsoft Edge WebView2 Runtime, which is installed as a dependency, and ships with its own Java runtime.

**Please Note**: This is an automatically updated package. If you find it is out of date by more than a day or two, please contact the maintainer(s) and let them know the package is no longer updating correctly.
