## Usage

To install Tailscale, run the following command from the command line or from PowerShell:

```powershell
choco install tailscale
```

To upgrade Tailscale, run the following command from the command line or from PowerShell:

```powershell
choco upgrade tailscale
```

To uninstall Tailscale, run the following command from the command line or from PowerShell:

```powershell
choco uninstall tailscale
```

## Description

The Tailscale client allows you to connect all your devices using WireGuard, without the hassle. Tailscale makes it as easy as installing an app and signing in.
