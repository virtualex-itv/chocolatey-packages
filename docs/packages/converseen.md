## Usage

To install Converseen, run the following command from the command line or from PowerShell:

```powershell
choco install converseen
```

To upgrade Converseen, run the following command from the command line or from PowerShell:

```powershell
choco upgrade converseen
```

To uninstall Converseen, run the following command from the command line or from PowerShell:

```powershell
choco uninstall converseen
```

## Description

Converseen is a free batch image processor. It lets you convert, resize, rotate and flip any number of images with a single mouse click. Built on the ImageMagick library, it handles more than 100 image formats, including DPX, EXR, GIF, JPEG, JPEG-2000, PNG, SVG, TIFF, WebP and HEIC/HEIF.

### Features

* Single or multiple conversions
* Resize one or many images, with a choice of resampling filter
* Compress images for web pages
* Rotate and flip images
* Rename a set of images with a progressive number or a prefix/suffix
* Convert an entire PDF to a set of images
