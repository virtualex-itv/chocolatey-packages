## Usage

To install EmEditor, run the following command from the command line or from PowerShell:

```powershell
choco install emeditor
```

To upgrade EmEditor, run the following command from the command line or from PowerShell:

```powershell
choco upgrade emeditor
```

To uninstall EmEditor, run the following command from the command line or from PowerShell:

```powershell
choco uninstall emeditor
```

## Description

EmEditor is a fast, lightweight text editor for Windows. It opens very large files, handles Unicode and many encodings, and includes powerful find and replace, multiple selections, macros, a CSV editor and syntax highlighting.

### Package Notes

* This package installs the 64-bit MSI installer, which the vendor calls the legacy installer. The vendor has announced that updates for the MSI installer will end in March 2027.
* The MSI installs EmEditor for the Windows account that runs Chocolatey (in that account's `%LOCALAPPDATA%\Programs\EmEditor` folder), not for every user of the computer.
* EmEditor Professional is commercial software. After installation all Professional features are available for 7 days. The trial then switches to EmEditor Free automatically, unless a Professional license is purchased.
* EmEditor Free is for personal use at home or at school only. It may not be used in corporate, government, or other organizational environments.

**Please Note**: This is an automatically updated package. If you find it is out of date by more than a day or two, please contact the maintainer(s) and let them know the package is no longer updating correctly.
