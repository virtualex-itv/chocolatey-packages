## Usage

To install ShareFile for Windows, run the following command from the command line or from PowerShell:

```powershell
choco install sharefile-for-windows
```

To upgrade ShareFile for Windows, run the following command from the command line or from PowerShell:

```powershell
choco upgrade sharefile-for-windows
```

To uninstall ShareFile for Windows, run the following command from the command line or from PowerShell:

```powershell
choco uninstall sharefile-for-windows
```

## Description

ShareFile is a file sharing service for exchanging documents securely. ShareFile for Windows lets you access your ShareFile files from a drive in Windows Explorer. Files are downloaded only when you open them and are kept on your computer temporarily, and changes you make are saved back to ShareFile automatically.

### Package Notes

* ShareFile for Windows requires a ShareFile account.
* The x64 installer is used on x64 Windows and the native ARM64 installer on ARM64 Windows. ShareFile publishes no 32-bit installer.
* The installer adds the Microsoft Edge WebView2 Runtime and the Visual C++ runtime if they are missing.
