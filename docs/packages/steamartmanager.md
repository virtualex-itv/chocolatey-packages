## Usage

To install Steam Art Manager, run the following command from the command line or from PowerShell:

```powershell
choco install steam-art-manager
```

To upgrade Steam Art Manager, run the following command from the command line or from PowerShell:

```powershell
choco upgrade steam-art-manager
```

To uninstall Steam Art Manager, run the following command from the command line or from PowerShell:

```powershell
choco uninstall steam-art-manager
```

## Description

Steam Art Manager is a simple and elegant tool for customizing your Steam library. Browse and apply custom grids, heroes, logos and icons for the games in your library, with artwork sourced from SteamGridDB.

### Features

* Set custom grids, heroes, logos and icons for any game, including non-Steam games
* Browse and download community artwork from SteamGridDB
* Preview changes before applying them and revert at any time
* Back up and restore your customizations
