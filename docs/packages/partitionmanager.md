## Usage

To install Paragon Partition Manager Community Edition, run the following command from the command line or from PowerShell:

```powershell
choco install partition-manager
```

To upgrade Paragon Partition Manager Community Edition, run the following command from the command line or from PowerShell:

```powershell
choco upgrade partition-manager
```

To uninstall Paragon Partition Manager Community Edition, run the following command from the command line or from PowerShell:

```powershell
choco uninstall partition-manager
```

## Description

Paragon Partition Manager Community Edition is a free partition manager for Windows. It resizes, moves, creates, formats and checks partitions on internal and external disks, and it can recover accidentally deleted partitions.

### Features

* Resize and move partitions, or enter the exact size you want
* Expand a partition into unallocated space or free space on adjacent volumes
* Create, format and delete partitions on HDDs, SSDs, USB drives and memory cards
* Undelete partitions and recover the data on them
* Change volume labels and drive letters
* Test the surface of a partition for errors and fix them
* Convert between logical and primary partitions, MBR and GPT disks, and HFS to NTFS without reformatting

### Package Notes

* Paragon offers the Community Edition free for personal and home use only. Business use is not allowed; for that, see Paragon Hard Disk Manager for Business.
* On first launch the app asks you to continue with a Google or Microsoft account to start an evaluation period. The package cannot do this for you.
* Requires 64-bit Windows 10 (version 1809 or later) or Windows 11. Windows Server is not supported. Both x64 and ARM64 are supported, and the matching installer is chosen automatically.
* The package version is the installer's own version, as shown in Programs and Features. It can differ from the version Paragon shows in the app and in the shortcut names.
* The installer also creates a shortcut on the Public Desktop.
