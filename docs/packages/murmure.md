## Usage

To install Murmure, run the following command from the command line or from PowerShell:

```powershell
choco install murmure
```

To upgrade Murmure, run the following command from the command line or from PowerShell:

```powershell
choco upgrade murmure
```

To uninstall Murmure, run the following command from the command line or from PowerShell:

```powershell
choco uninstall murmure
```

## Description

Murmure is a privacy-first, open-source speech-to-text application that runs entirely on your machine. A neural network, NVIDIA's Parakeet TDT 0.6B v3 model, transcribes your voice locally, so no audio or text ever leaves your computer and no network connection is required.

### Features

* All processing happens on your device, with no telemetry or analytics
* Supports 25 languages
* Dictate into any application, including AI prompts, notes and documents
* Optional post-processing with a local LLM to translate, fix grammar and more

### Package Notes

* The installer is large (about 640 MB) because it includes the speech recognition model.
* Murmure requires Windows 10 or later and installs the 64-bit MSI.
