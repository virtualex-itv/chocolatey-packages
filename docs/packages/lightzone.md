## Usage

To install LightZone, run the following command from the command line or from PowerShell:

```powershell
choco install lightzone
```

To upgrade LightZone, run the following command from the command line or from PowerShell:

```powershell
choco upgrade lightzone
```

To uninstall LightZone, run the following command from the command line or from PowerShell:

```powershell
choco uninstall lightzone
```

## Description

LightZone is a professional-level digital darkroom and photo editor with RAW processing. Rather than layers, it lets you build a stack of tools that can be rearranged, readjusted, turned off and on, and removed. It is a completely non-destructive editor: any tool can be re-adjusted later, even in a different editing session. A tool stack can be copied to a batch of photos at one time. LightZone always works in a 16-bit linear color space with the wide gamut of ProPhoto RGB.

### Features

* Reads RAW files from a variety of cameras and displays their metadata
* Star ratings and batch processing
* Style filters such as Alien Infrared, Skin Glow and Polarizer
* Non-destructive tools including relight, sharpen, gaussian blur, hue/saturation, color balance, white balance, black and white, noise reduction, clone, spot and red eyes
* Crop, rotation and region editing modes, and raw tone curve modification
