## Usage

To install Gemini Desktop, run the following command from the command line or from PowerShell:

```powershell
choco install gemini-desktop
```

To upgrade Gemini Desktop, run the following command from the command line or from PowerShell:

```powershell
choco upgrade gemini-desktop
```

To uninstall Gemini Desktop, run the following command from the command line or from PowerShell:

```powershell
choco uninstall gemini-desktop
```

## Description

Gemini for desktop is Google's AI assistant as a native Windows app. Press Alt + Space from anywhere to summon Gemini over whatever you are working on, and use it alongside Gmail, Drive, Docs and Calendar.

The app is free to use with a Google Account. Selected features require a paid Google AI subscription (users 18+), and features vary by account type and region. Requires Windows 10 or later (x64).
