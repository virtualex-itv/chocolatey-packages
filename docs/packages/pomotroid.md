## Usage

To install Pomotroid, run the following command from the command line or from PowerShell:

```powershell
choco install pomotroid
```

To upgrade Pomotroid, run the following command from the command line or from PowerShell:

```powershell
choco upgrade pomotroid
```

To uninstall Pomotroid, run the following command from the command line or from PowerShell:

```powershell
choco uninstall pomotroid
```

## Description

Pomotroid is a simple, configurable Pomodoro timer. It tracks work and break rounds with a visually pleasing interface and keeps your session statistics.

### Features

* Configurable work and break durations and number of rounds per long break
* Daily, weekly and all-time statistics with charts and a 52-week heatmap
* 38 bundled themes plus custom themes, following the OS light and dark preference
* Global shortcuts, desktop notifications, a tray icon with live progress and an always-on-top option
* An opt-in local WebSocket server for stream overlays and integrations

### Package Notes

* This package installs the 64-bit installer for all users.
* Pomotroid runs on the Microsoft Edge WebView2 Runtime, which is installed as a dependency.
